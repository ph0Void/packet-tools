# PACKET TOOLS (legacy)

Sistema de gestión de red con topología visual, monitorización en tiempo real y agente inteligente.

## 🚀 Características

- **Topología Visual**: Detección automática y representación gráfica de la red.
- **Monitorización en Tiempo Real**: Estado de dispositivos (online/offline) y enlaces.
- **Agente Inteligente**: Detección automática de fallos y diagnóstico asistido por IA.
- **Panel de Control**: Herramientas para diagnóstico, recuperación de estado y gestión de estado de enlaces/dispositivos.
- **Guardado Persistente**: Guarda los datos en una base de datos SQLite.

## 🛠️ Tecnologías

- **Sistema**: Next.js, React, Tailwind CSS
- **Comunicación**: WebSocket, Socket.io

## 🛠️ Herramientas Disponibles

### Dashboard
- **Topología**: Arrastrar y soltar dispositivos.
- **Diagnóstico**: Detectar fallos y ejecutar comandos de troubleshooting.
- **Estado**: Activar/desactivar dispositivos y enlaces.
- **Puente WebSocket**: Comunicación en tiempo real con el backend.
